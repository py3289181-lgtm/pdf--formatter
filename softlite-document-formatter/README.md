## 🌟 Overview
`softlite-document fometer` is a full-featured, desktop-grade web document editor and PDF formatter designed with an intuitive Microsoft Office 365 style Ribbon interface, Canva/Photoshop-style Free Transform engine, digital ink drawing canvas, fillable form creator, and reference toolset.

---

## 🚀 Key Features

### 1. Startup & Templates Modal
- **Automatic Launch Screen**: Opens directly on launch with a template picker and file open dialog.
- **5 Built-in Templates**:
  1. **Blank Document**: Clean slate with standard A4 margins.
  2. **Modern Resume / CV**: Executive multi-column profile layout.
  3. **Formal Business Letter**: Professional corporate letterhead with signature zone.
  4. **Professional Invoice**: Automated itemized billing table with taxes and totals.
  5. **Project Report & Proposal**: Academic/enterprise whitepaper with comparative tables.
- **Open File**: Load `.html`, `.json`, or `.txt` documents.

### 2. Home Tab & Typography
- **Font Selector**: Inter, Roboto, Poppins, Merriweather, Playfair Display, Arial, Courier New, Fira Code, Georgia, Calibri, Verdana.
- **Font Size**: 8pt to 72pt with instant preview.
- **Increment Font Size**: `Alt + Ctrl + A` (and Ribbon button).
- **Decrement Font Size**: `Alt + Ctrl + S` (and Ribbon button).
- **Styles**: Bold (`Ctrl+B`), Italic (`Ctrl+I`), Underline (`Ctrl+U`), Strikethrough.
- **Colors**: Full RGB Font Color & Highlight Color pickers.
- **Clear Style**: Instantly strip all formatting.
- **Paragraph Alignment**:
  - Align Left (`Ctrl + L`)
  - Align Center (`Ctrl + E`)
  - Align Right (`Ctrl + R`)
  - Justify (`Ctrl + J`)
- **Shading & Borders**: Background shading, Box borders, Bottom underline borders, Left callout accent borders.
- **Format Painter (Copy Style)**: Copy styles from any text and stamp onto selections.
- **Clipboard & Editing**: Cut (`Ctrl+X`), Copy (`Ctrl+C`), Paste (`Ctrl+V`), Find & Replace (`Ctrl+F` / `Ctrl+H`), Save (`Ctrl+S`), Print/PDF (`Ctrl+P`).

### 3. Insert Tab & Graphic Transform Engine
- **Tables**: Insert customizable grid tables with header rows.
- **Charts**: Dynamic SVG Bar, Pie, Doughnut, and Line charts.
- **Media & Shapes**: Local image upload, vector shapes (Rectangle, Rounded Rect, Circle, Triangle, Star, Arrow, Diamond, Heart).
- **SmartArt**: Process flows, pipelines, and step cards.
- **Floating Text Box**: Draggable and resizable anywhere on the canvas.
- **WordArt**: 6 stylized typographies (Neon Glow, 3D Extrude, Rainbow Gradient, Luxury Gold, Retro Wave, Hollow Bold).
- **World Map**: High-detail SVG global map with marker pins.
- **Currency & Symbols**: ₹, $, €, £, ¥, ₿, ₩, math symbols, Greek letters, and emojis.

### 4. Interactive Object Bounding Box & Free Transform
- **Move / Selection Tool**: Click and drag any photo, shape, text box, or SmartArt smoothly across the page.
- **Bounding Box (Transform Box)**: Dashed accent border with dimension HUD and quick delete/layer controls.
- **8 Resize Handles**: Corner and edge handles (`NW`, `N`, `NE`, `E`, `SE`, `S`, `SW`, `W`) for precision scaling.
- **Pivot Rotation**: Top rotation handle for full 360-degree rotation.
- **Free Transform (`Ctrl + T`)**: Photoshop-style transform mode for instant scaling and rotation.

### 5. Draw Tab (Digital Ink Canvas)
- **Ink Tools**: Fine Pen, Transparent Highlighter, Chisel Marker, Watercolor Brush, Rainbow Magical Brush (with sparkle stars), and Eraser.
- **Controls**: Thickness slider (1px - 40px), color picker, and clear canvas.

### 6. Forms Tab (Fillable PDF Elements)
- Text Field, Combo Box (autocomplete datalist), Dropdown List (select), Checkbox, Radio Button, Image Field placeholder.
- **Interactive Signature Pad**: In-app canvas pad where users can sign with mouse/touch and stamp their verified signature directly into the document.
- **Specialized Inputs**: Email address, Phone number, Date & Time picker, Zip code, Credit card number (with card icon).

### 7. References Tab
- **Table of Contents**: Scans `H1`, `H2`, `H3` headings and auto-generates a clickable TOC.
- **Add Text / Level**: Quick heading level markers.
- **Footnotes**: Automated superscript footnote numbering and page-bottom references.
- **Watermark**: Custom text, angle, opacity slider, and presets (CONFIDENTIAL, DRAFT, COPY).
- **Captions & Table of Figures**: Figure numbering and auto-index.

### 8. Layout Tab
- **Margins**: Normal (1 in), Narrow (0.5 in), Moderate, Wide (1.5 in).
- **Page Size**: A4, US Letter, Legal, A3.
- **Columns**: 1, 2, or 3 columns.
- **Multi-Page**: Insert Page / Page break.
- **Line Numbers**: Toggle gutter line numbers.
- **Indents**: Precise left and right indentation inputs.

### 9. Design, View, Plugins & Settings
- **Themes**: Modern Blue, Executive Slate, Emerald Green, Violet, Crimson.
- **View Controls**: Fullscreen (Full Size), Zoom In, Zoom Out, Fit to Page (100%), Ruler toggle.
- **Plugins**: One-click **Softlite Blue Theme Plugin** toggle.
- **About & License**: Displays app name `softlite-document fometer`, `built 100 2027`, `release 15/10/26`, and the full **Softlite Open-Source License**.
